# 08 — Recruitment (ATS) [V2]

> AI in hiring is regulated (EU AI Act high-risk; NYC LL144 bias audits). Orcavia AI in recruitment is
> **assistive and behind a per-tenant feature flag**: parsing, drafting, summarizing, scheduling.
> It never auto-rejects or ranks candidates without a human decision being recorded.

| ID | Requirement |
|---|---|
| REC-001 | Job requisitions: department, position, headcount, budget/salary band, justification, approval workflow; link to headcount plan [V3]. |
| REC-002 | Job postings: AI-assisted job description (from title + requisition + similar roles), inclusive-language check; publish to a branded careers page; share links; integrations with job boards (LinkedIn, Rozee.pk, Indeed, Bayt ⚠️ confirm). |
| REC-003 | Application form builder with knock-out questions; candidate portal with status tracking. |
| REC-004 | CV parsing (PDF/DOCX/image) into structured profile; duplicate candidate detection; talent pool search (keyword + semantic). |
| REC-005 | Pipeline per job with configurable stages (Kanban), bulk actions, email/WhatsApp templates, candidate communications log. |
| REC-006 | AI candidate summary against the job's requirements: matched/missing must-haves with evidence quotes from the CV — shown as *notes for the recruiter*, no score by default. Optional scoring only if tenant enables it, with bias audit reporting. |
| REC-007 | Interviews: scheduling with calendar integration (Google/Microsoft) and candidate self-scheduling, panels, structured interview kits (questions + scorecards), AI-generated question sets per competency. |
| REC-008 | Feedback/scorecards, hiring decision with reason, debrief view. |
| REC-009 | Offers: offer letter from template, approval workflow (salary outside band → extra approval), e-sign, offer acceptance converts candidate → pre-boarding employee (ONB-001). |
| REC-010 | Referrals program with referral bonus tracking. |
| REC-011 | Recruitment analytics: time-to-hire, source effectiveness, funnel conversion, diversity (opt-in data, aggregated). |
| REC-012 | Candidate data retention and consent (delete after N months unless consented to talent pool). |
| REC-013 | Assessments integrations (coding tests etc.) [V3]. |
